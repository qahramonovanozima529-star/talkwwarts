# Talkwarts Image Assets

Place the following transparent PNG files in this directory:

- `platform934.png` — Step 1: Platform 9¾ welcome scene
- `harry.png` — Step 2: Authentication step illustration  
- `cat.png` — Step 3: The Sorting oracle character
- `owl.png` — Step 4: Athena the AI Companion
- `letter.png` — Step 5: The acceptance letter
- `quill.png` — Step 5: The enchanted quill (floats above the letter)

All images should be transparent PNGs for best results with the dark background and drop shadows.
Recommended dimensions: at least 512×512px for quality display.
